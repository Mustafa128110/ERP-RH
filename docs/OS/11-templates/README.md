# Templates — Usage Contract

- Every repeated document starts from its template. Writing from
  scratch when a template exists is a defect — it's how consistency
  dies.
- Fields in [BRACKETS] are fill-ins; guidance in (parentheses) is
  deleted before use.
- Customer-facing templates ship EN + UR (UR via translate-ur
  prompt, owner-reviewed). Internal templates are EN, Urdu added
  as staff needs grow (CONTRIBUTING.md).
- Templates are law-bearing: each embeds the rules that govern its
  document type (vocabulary, architecture, register). Changing a
  template is changing policy → PR + CHANGELOG.
- Skills reference templates by path; a template rename is a
  breaking change.
