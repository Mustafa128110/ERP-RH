# Template: Email (5 types, one layout)

**Layout (all):** white ground · navy-800 header band with wordmark
· brass hairline rule under header · body Inter 16 · footer: NAP +
WhatsApp + unsubscribe. One CTA per email. Vocabulary law applies.

## Type A — Order confirmation (transactional)
Subject: Order [#] confirmed — Royal Hardware
Body: greeting [name] → order table (items, qty, prices tabular) →
what happens next (1–2 lines) → WhatsApp help line → footer.

## Type B — Dispatch
Subject: Order [#] shipped — tracking inside
Body: courier + tracking number (large, tappable) → honest ETA →
"reply on WhatsApp if anything's off" → footer.

## Type C — Abandoned cart (ONE send, 6–12h)
Subject: Your items are still in the cart
Body: the items (image+name+price) → "if a question stopped you,
WhatsApp us" → cart link. NO countdowns, NO discount bribes.

## Type D — Monthly digest
Subject: [Month] at Royal Hardware — [one concrete hook]
Body: new stock (2–3 items) → one guide → one tip → single CTA.

## Type E — B2B price-list update (formal register)
Subject: Price list update — effective [date]
Body: what changed and why (one honest line) → effective date
BEFORE their next order cycle → attached/linked list → account
contact line.
