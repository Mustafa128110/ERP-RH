# Brand Book, Part V: Iconography

## Style DNA
Outline, 2px stroke, squared joints and terminals, 24px master grid
with 2px padding — drawn like engineering linework, not app-store
cuteness. Corner radius inside icons ≤1px. Optical, not mathematical,
centering.

## Sources
- Base set: Tabler Icons (matches the DNA out of the box).
- Custom set (commission with the logo, same designer, same grid):
  8 category icons — power tools, hand tools, disc, shovel, chain,
  lock, safety, construction — plus 5 badge icons: Genuine (seal-
  derived), Warranty, Nationwide, COD, Since-1990.

## Color & Scale Law
Steel default · navy active/hover · brass EXCLUSIVELY on
genuine/premium badges (the seal logic). Sizes 16/20/24/32 only,
scaled from the 24px master — never arbitrary, never mixed metaphors
(one icon per concept, reused everywhere: the same disc icon in nav,
filters, and footer).

## Don'ts
Filled styles · rounded-bubbly sets · multicolor icons · icon
decoration where a word is clearer · hand-drawn one-offs outside
the grid.
