# Brand Book, Part VI: Digital Surface

The website should feel like a well-run counter: everything visible,
everything labeled, nothing shouting. "Machined calm."

## Surface Language
- White stage; ivory alternating bands; ONE navy band per page
  (hero or footer) as the anchor of authority.
- Hairlines (1px sand) structure the page; heavy borders and drop
  shadows are admissions of failure. Elevation only where function
  demands (dropdown, modal, sticky header).
- The brass moment: one per view — the genuine badge, a rule under
  the hero line, or the seal. Choose.

## Signature Components (specs live in 07-design-system)
- **Trust microbar** above nav: "Genuine stock · Since 1990 ·
  Nationwide COD" — small, steel, always there, never animated.
- **The Genuine badge**: brass-100 ground, brass-600 seal icon,
  navy text. The most protected element in the system: only on
  products, never on promotions.
- **Price block**: navy tabular price + honest unit ladder hint on
  consumables ("piece / box / carton — trade rates on WhatsApp").
- **Buttons**: navy primary · outlined secondary · brass reserved
  for add-to-cart/checkout (the transaction is the ceremony).
- **Product card**: white, sand hairline, photo-led, two badges max.

## Motion Character — "precision machinery"
Damped, deliberate, brief: 150–400ms, ease-out, the machined curve
(cubic-bezier(.22,1,.36,1)). Reveals rise 20px and settle ONCE.
Lenis adds weight (lerp 0.1), never float. Nothing loops, nothing
bounces, nothing spins. Reduced-motion kills it all. Full vocabulary:
07-design-system/motion.md.

## RTL Dignity
The Urdu experience mirrors fully and keeps every standard — same
spacing, same hierarchy, Nastaliq display sized generously. An Urdu
visitor should feel the site was designed in Urdu, not translated
into it.

## The Test
Screenshot any view. Cover the logo. If it could be any store, it
fails: the navy anchor, the hairline order, the one brass moment,
and the photography register should identify Royal Hardware alone.
