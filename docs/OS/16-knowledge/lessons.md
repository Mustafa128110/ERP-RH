# Lessons — What Worked

The mirror of mistakes.md: successes captured with the same
discipline, because unexamined wins don't repeat either.
Consumers: the monthly roll-up · prompt-library gold examples ·
SOP improvements · marketing-copy (what converted becomes
template material).

## Entry format
### [YYYY-MM-DD] · [one-line title] · Domain: [sales / ops /
content / trade / support]
**What we did:** · **What happened:** (with the number if one
exists) · **Why we think it worked:** · **Repeatable?** [yes →
where it now lives (SOP/template/prompt patched) / one-off / test
again]

The "where it now lives" line is the point: a lesson that doesn't
change a document is a story, not a lesson.

Seed candidates from launch onward: the broadcast that got
replies · the packing method that cut damage · the phrase
customers respond to at the counter (36 years of these exist —
capture them as they surface in daily work).
