# meeting-notes/README.md

One file per meeting, named [YYYY-MM-DD]-[type].md, from
11-templates/meeting-notes.md. Types: weekly-ops · quarterly ·
supplier · owner-self-review.

The extraction law: a meeting file is a SOURCE, not a home.
Decisions worth keeping → decision-logs/. Lessons → lessons.md.
Ideas → ideas.md. Numbers → their KPI homes. The meeting note
itself is the audit trail of where things went — each extracted
item gets its destination link inline.

The owner self-review (monthly, 30 min, honest): what did I avoid
this month · which checklist items am I rubber-stamping · what am
I doing that staff/AI should own by now. Filed like any meeting —
the system's operator is also inside the system.
