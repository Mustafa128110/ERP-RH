# Best Practices — Adopted, With Provenance

External practices we deliberately adopted — recorded so we know
what's borrowed, why, and where it now lives (once adopted, the
practice's real home is the SOP/standard it patched; this file is
the provenance index).
Consumers: documentation skill (consistency sweeps) · onboarding.

## Entry format
### [practice] · adopted [YYYY-MM]
**Source:** (where it came from) · **Why it fit us:** (the test:
does it serve a pillar or a law we already hold?) · **Where it
now lives:** [SOP/standard/checklist link] · **What we changed:**
(we adapt, never transplant — the adaptation note is the
knowledge)

## The rejection ledger (equally valuable)
Practices considered and declined, one line each with the why —
"industry standard" ideas that fight our positioning (countdown
timers, discount ladders, marketplace-first) get named here so
they're declined ONCE, not annually.
