# Knowledge Base — Contract

## Why this folder exists
36 years of judgment currently lives in one head. This folder is
where it becomes an asset the business owns: transferable to
staff, readable by AI, survivable past any single person. It is
also where the system LEARNS — every mistake, experiment, and
supplier fact captured here makes every future decision cheaper.

## The three capture laws
1. **Same-day capture.** Knowledge is written the day it's
   learned, by whoever learned it, in plain language. An insight
   that waits for "when I have time" never happened
   (memory-rules.md, applied to humans too).
2. **Formatted entry.** Every file defines its entry format below.
   Formatted knowledge is queryable; prose diaries are write-only.
3. **Named consumer.** Each file states who/what reads it and
   when. Knowledge nobody consumes is a graveyard — if a file's
   consumer disappears, the file gets a new one or gets archived.

## Review rhythm
Monthly: lessons + mistakes roll-up (owner, 20 min — patterns
promoted to SOP/doc patches). Quarterly: suppliers, competitors,
experiments read-through feeding the deep review (15-analytics).
Annually: the full folder read start to finish — the cheapest
strategy consultant the business owns.

## Access
suppliers.md and anything with commercial terms: owner +
explicitly named staff only. The rest: all staff read, all staff
write (capture is everyone's job).
