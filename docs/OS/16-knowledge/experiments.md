# Experiments — The End of "We Think"

Every deliberate test, recorded so debates die of evidence.
Consumers: the monthly one-pager step 5 · quarterly deep review ·
the annual read-through · analytics-review (checks what's been
tried before proposing it again).

## Entry format
### EXP-[NNN] · [name] · [start → end dates]
**Hypothesis:** (falsifiable: "X will improve Y by roughly Z
because…")
**Change made:** (exactly one variable — the CRO one-fix law)
**Measured on:** (the KPI + its 15-analytics definition)
**Result:** (the number, vs baseline)
**Verdict:** adopt (→ where it now lives) / reject (→ why) /
rerun (→ what was confounded)

## Laws
- One variable per experiment; overlapping tests on the same
  funnel step are void (funnels.md rule).
- 30-day minimum unless the metric is fast (ad kills are weekly
  by design and logged as one-line entries).
- Rejected experiments are as valuable as adopted ones — they're
  roads nobody has to walk twice.
- The ledger is read BEFORE proposing: re-running a settled
  experiment without new conditions is a defect.
